# Micro-SaaS Financial Dashboard 📊

لوحة قيادة مالية تفاعلية مصممة بعناية بنظام (Dark Mode) لإدارة ومتابعة الأداء المالي، المستحقات، والمصاريف.

## المميزات الرئيسية:
- متابعة لحظية لإجمالي الإيرادات، المصاريف، الأرباح، والمستحقات.
- فصل واضح بين المشتريات والمستحقات والديون.
- تصميم عصري واحترافي مناسب لأنظمة Micro-SaaS.
